Evidencia real (somente leitura) para a critica do plano do MCP do Dominio.

Todos os arquivos 01..06 sao a saida bruta de scripts que rodaram em 21/11/2026 contra o banco real
(SQL Anywhere 17.0.11.7312, DSN de sistema 64 bits "contabil", usuario EXTERNO) e contra o dump local do
catalogo. Nenhum dado de negocio foi lido: so metadados (SYS.*), SELECT ... WHERE 1=0, contagens e WAITFOR.

01-driver-battery.txt        timeout ODBC (HYC00), cancel() por thread, access-mode, isolation_level, fetchmany, START AT, decodificacao.
02-charset-codepoints.txt    AUTORIDADE sobre acentos: pontos de codigo por estrategia de conexao/decodificacao.
03-permission-probe.txt      quais objetos o usuario EXTERNO consegue ler (4946 de 4964).
04-catalog-metrics.txt       prefixos de modulo, legendas, campos obsoletos, regras de sensibilidade, hubs de FK.
05-retrieval-prototype.txt   recall do prototipo de busca de esquema (26 perguntas em portugues).
06-sqlglot-dialect.txt       sqlglot nao entende o dialeto SQL Anywhere (CURRENT DATE, START AT).

ATENCAO: o terminal que capturou estas saidas desenha acentos de forma errada (aparece "inscri??o" ou
"Lan?amento" quando o dado esta correto). NAO conclua nada sobre acentuacao a partir do texto de 01 (T6) nem
de listas de nomes; use 02, que imprime U+00E7 U+00E3 (c-cedilha, a-til) em vez do glifo.
